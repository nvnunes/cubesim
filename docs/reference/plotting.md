# Plotting API

Import plotting from its public submodule:

```python
import cubesim.plotting as plotting
```

Plotting functions accept immutable results, create a Matplotlib figure, and
return it without showing, saving, or closing it. See the
[Python API guide](../api.md#plot-results) for selector conventions and
[Results And Persistence](results.md) for the plotted products.

::: cubesim.plotting
    options:
      members_order: source
      show_root_heading: true
      show_source: false
